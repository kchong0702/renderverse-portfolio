# Optimise a résumé for applicant tracking systems

1. Load the `modify-career-documents` skill. Make every change below as an edit, the way it describes.
2. List the posting's required skills, tools and job titles, using the posting's own words.
3. For each one, find the PDF line or profile fact that shows the user has it. Skip anything with no line or fact. Never add a skill, tool or title the user hasn't shown.
4. Where the résumé says the same thing in other words, reword it to the posting's term and cite the original line. Cite a fact as well when the term comes from the fact.
5. Move the most relevant bullets to the top of each job, and the most relevant section above the less relevant ones.
6. Add a missing skill to the skills section only when a fact shows it.
7. Keep standard section headings such as Experience, Education and Skills, so tracking systems read them.
8. Keep the length. A one-page résumé stays one page, so remove or shorten the least relevant bullets before you add new ones.
